1. Project Title 
GlobeCast: Discover Emerging Actors Globally


2. Overview / Description 
GlobeCast is a web platform designed to spotlight emerging actors from around the world. Users can click on any country on an interactive map and discover an up-and-coming actor from that region along with a featured film. The project was built to address the lack of diversity in mainstream media by giving underrepresented international talent a place to be seen. Rather than sticking to Hollywood-centric recommendations, GlobeCast encourages users to explore talent they would never come across otherwise.


3. Key Features and Functionality
Interactive world map where users can click any country
Displays an emerging actor and their associated film per country
Clean, user-friendly interface built for easy navigation
Designed with diversity and global representation in mind


4. Tech Stack 
- HTML — page structure and layout
- CSS — styling and visual design
- JavaScript — interactive map logic and button functionality
- GitHub — version control and collaborative branching

5. Timeline

  3. Built the base HTML/CSS layout and page structure

  5. Tackled the interactive map and connecting country clicks to actor data
  6. Tested the interface and refined the design

6. Challenges
Getting started was honestly one of the harder parts. We had a solid idea but weren't immediately sure how to bring it to life technically. We spent time exploring different tools and approaches before landing on our final stack. The interactive map was probably our biggest technical hurdle — getting it to respond to user input and correctly map countries to the right data took a lot of trial and error. On top of that, coordinating work across GitHub branches was new to all of us, so there was a learning curve there too. Looking back, the biggest takeaway was that nailing down your idea first and then picking your tools makes the whole process a lot smoother.
